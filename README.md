# 🥋 Regex Dojo

![Regex Dojo Logo](./regex_dojo.png)

Bienvenido a **Regex Dojo**, un espacio de práctica para dominar las **expresiones regulares** mediante ejercicios de distinta dificultad.  
La idea es entrenar como en un dojo: disciplina, constancia y retos progresivos.

---

## 📖 Descripción
- Este proyecto contiene **ejercicios prácticos de expresiones regulares** en Bash.  
- Los ejercicios van desde lo más básico hasta casos avanzados.  
- Con el tiempo se irán **agregando más ejercicios** y nuevas funciones.  
- Invitamos a la comunidad a **crear y compartir ejercicios** para enriquecer el dojo.  

---
